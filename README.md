# Training an AI to hike

### How it works

- We create a 3d terrain reconstruction of a geographic area using topographical data merged with OSM trail data and landsat foliage coverage
- We create a RL model agent with full control over a human body with limbs. Give it a trail map and a view of the surroundings
- Hope that it can make it to a point on the trail
